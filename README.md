# Python Basics — Complete Fundamentals Guide

A comprehensive, beginner-friendly Python reference with clear explanations, practical examples, and outputs in one Jupyter Notebook.

The repository starts with core Python syntax and gradually introduces concepts commonly used in programming and data analysis.

## Topics Covered

### Python Fundamentals
- Printing and comments
- Variables and naming conventions
- Data types: strings, integers, floats, booleans, and `None`
- Type conversion
- Arithmetic, comparison, logical, and membership operators
- Strings, indexing, slicing, formatting, and common string methods

### Python Collections
- Lists and common list methods
- Tuples and tuple unpacking
- Sets and set operations
- Dictionaries and key-value operations

### Control Flow
- `if`, `elif`, and `else`
- Conditional expressions
- `for` loops
- `while` loops
- `range()`
- `break` and `continue`
- `enumerate()`
- `zip()`

### Functions
- Defining and calling functions
- Parameters and return values
- Default parameters
- Positional and keyword arguments
- `*args` and `**kwargs`
- Local and global scope
- Lambda functions
- `map()`, `filter()`, and `sorted()`

### Pythonic Programming
- List comprehensions
- Set comprehensions
- Dictionary comprehensions
- Useful built-in functions
- Iterators
- Generators and `yield`

### Error and File Handling
- `try`, `except`, `else`, and `finally`
- Raising exceptions
- Reading and writing text files
- File modes and the `with` statement
- JSON serialization and deserialization

### Object-Oriented Programming
- Classes and objects
- Attributes and methods
- `__init__`
- Inheritance
- Dataclasses

### Standard Library Examples
- `math`
- `statistics`
- Regular expressions with `re`
- Dates with `datetime`
- Random values with `random`

### Data Science Foundations
- NumPy arrays
- Vectorized operations
- Aggregation
- Array shapes and reshaping
- Boolean filtering
- pandas DataFrames
- Column selection
- Row filtering
- Creating columns
- Grouping and aggregation

### Development Practices
- Python naming conventions
- Readable code and PEP 8 basics
- Docstrings
- Virtual environments
- `pip`
- `requirements.txt`

### Practice
The notebook finishes with a mini student-score project combining collections, functions, loops, conditions, comprehensions, and aggregation.
